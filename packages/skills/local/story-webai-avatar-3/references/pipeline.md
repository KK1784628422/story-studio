# 3.0 流水线 — 审美筛查 + Creative Meeting + 七大模块

> 三段式：审美上游决定「值不值得拍」，导演层决定「怎么拍」，转译层决定「豆包接不接得住」。
> 纪律：不得跳步，不得拿到角色卡就直接写 Prompt。

## 一、审美筛查（上游放行门，源自 mj-aesthetic-director）

### 静帧四问（任一不过 → 换场景重做，不靠加特效补救）

1. **第一眼是否已经好看？**（不依赖文字解释、不依赖观众找线索）
2. **视觉中心是否自然形成？**（可来自人物，也可来自光、色、建筑、水面、材质、空间关系）
3. **是否只有一种清晰的主感受？**（清冷 / 湿润 / 肃静 / 危险 / 温暖……一张图只负责一种）
4. **删掉「发生了什么」之后，画面是否仍然成立？**（删掉事件就垮 = 过度依赖剧情）

### 八条原则速记

1. 不要把成功样本归纳成公式：武侠≠拿剑、漂亮≠必须异常、电影感≠小人物大景、意境≠空旷；
2. 大众审美 = 低理解门槛，不是题材下沉；
3. 武侠/仙侠是世界观（山水材质天候克制），不是动作模板（不要求拔剑/决斗/轻功）；
4. **美感发动机要轮换**：光线 / 色彩 / 空间 / 材质 / 天候介质 / 人物状态 / 异常——同书多角色相邻两张不能同发动机；
5. 防「AI 古风大片」同质化：连续都拿剑、都月夜、都大景小人、都飞叶 → 下一张至少切两个维度（景别/时间/主色/空间/密度）；
6. 剧情只是加分项：画面漂亮 → 氛围成立 → 人物嵌入 → 有余力再加故事；
7. 最终判断句：「这是一张先天就好看的画面，还是一个需要我解释为什么好看的点子？」只保留前者；
8. 角色头像特殊性：人物必在（与纯场景不同），但「人物是视觉主体还是环境尺度」仍要决策——气场型角色人物即中心，融入型角色环境即中心。

### 筛查产出（一句话汇报）

> 这一帧主要靠 ______ 成立（写 1-2 个美感发动机），主感受是 ______。

## 二、Creative Meeting（中文会议纪要，展示给用户）

五个角色依次发言，先做视觉决策再写词：

```
Director         这一幕真正拍的是什么（情绪主题，不是物体）——「她在称量人心」而非「她拿着算盘」
Cinematographer  焦段 / 机位 / 人物占比（具体百分比）/ 摄影机在环境内部还是外部
Art Director     主色 2-3 个 + 明度秩序（最亮处是什么、人物是明度极端吗）
Creative Director Visual Hook：第一眼→第二眼→第三眼看什么
Story            这一秒刚刚发生了什么（前一秒，不是状态）
```

## 三、七大模块（英文产出，展示给用户，每模块标注模块名）

### Module 1 · Character DNA

人物是谁，观众第一眼为什么愿意看她/他。三件套：**原型底稿**（2.0 的 archetypes.md 原型库可参照气质分类）+ **反差设计**（气质×五官的反差，不靠妆容）+ **骨相规格**（读 `bone-structure.md`，成年头像必选一套，转译时全肯定句融入）。

禁：perfect face / flawless / doll face / large eyes / full lips / gentle / tiny waist / oversized eyes。

### Module 2 · Attention（灵魂模块）

人物此刻把注意力放在哪里。**注意力对象 = 视觉锚点 = 画面最亮处**：

| 注意力指向 | 画面主题 |
|---|---|
| 看远方 | 等待 |
| 看天空 | 向往 |
| 看手中之物（剑/信/药碗） | 回忆 / 羁绊 |
| 看另一个人 | 关系 / 对峙 |
| 看地面 | 疲惫 / 沉思 |
| 闭眼 | 感受 / 承受 |
| 看镜头 | 几乎永远禁止（立刻变写真）——气场型角色例外但神态必须具体 |

句式库：

```text
Her attention belongs entirely to the sword. She never notices the camera.
Her eyes quietly follow the blade instead of looking into the distance.
She is not inspecting the weapon. She seems to be remembering something.
She quietly watches the reflection upon the blade, completely absorbed in her own thoughts.
He does not notice the camera. He only watches the reflection upon the steel.
```

### Module 3 · Story Moment

这一秒**刚刚**发生了什么——写「刚刚/前一秒」不写状态：「指尖刚停在一颗没推完的算珠上」优于「他在算账」。「什么都没发生」也是强瞬间。给动机暗示但不说破（she seems to be remembering something——观众大脑自动补故事）。

### Module 4 · Photography Strategy（决策清单逐项）

```
镜头焦段     头像默认 85mm（气场型可 50mm 近；融入环境型可 35mm 环境人像）
机位角度     Eye Level 默认；威仪型低 10°；审视型高 10°
主体占比     具体百分比（人像甜区 30-50%：气场型取高值，融入型取低值）
光源         唯一可信来源；先照什么（空间/悬浮物/注意力对象）、最后才照脸；最亮处点名
背景关系     三层：前景静锚点 → 中景人物 → 背景氛围溶解
空间关系     摄影机在环境内部（被包围感）还是外部（观察感）
```

气质决定策略：**甜妹拍柔，御姐拍硬，侠女拍静，女帝拍尺度，谋士拍静，武将拍重。**

```text
Medium portrait. 85mm cinema lens. Eye-level camera.
The camera remains inside the bamboo forest rather than above it.
The moon itself never appears. Only moonlight filtering through bamboo leaves
becomes the light source. The subject occupies about forty percent of the frame.
```

### Module 5 · Visual Hook

第一眼 → 第二眼 → 第三眼的视线路径（三眼设计）：第一眼 = 最亮处（= 注意力对象）；第二眼 = 眼神/神态；第三眼 = 环境/时代/彩蛋。停留来自视觉反差，不是感官刺激。

### Module 6 · Photographer's Notes（摄影哲学句式，选 3-5 句）

```text
Observe her attention before observing her beauty.
Observe the light before observing the face.
The portrait feels like the camera has accidentally witnessed a private moment.
Nothing feels posed. Nothing feels performative.
Avoid visual spectacle. Leave empty space. Leave ambiguity.
Trust natural light. Trust quiet observation.
Let the viewer slowly discover the image.
```

### Module 7 · Director's Observation（收尾情绪段，2-4 句现在时观察）

零物体却改变构图与情绪的句子：

```text
The landscape remains indifferent to human presence.
The entire room seems to hold its breath.
The morning does not care about his hesitation.
She verifies before she saves.
```

## 四、与输入端五规则的接线

- 彩蛋规则 → Module 1 服装磨损细节 + Module 5 第三眼彩蛋；
- 反差规则 → Module 3 Story Moment 的对位 + Module 7 收尾对位句；
- 可视化规则 → Module 1 禁形容词 + Module 2 Attention 具体化；
- 色调对位规则 → Creative Meeting Art Director 发言 + 转译层明度定位；
- 时代考据规则 → Module 4 背景三层 + Scene 五要素的 Location/Time。
