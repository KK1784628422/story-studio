## 1. 分层同步核对（大纲体系纵向）

- [ ] **总纲 ↔ 卷纲**：主线阶段数 / 单元数一致？每卷字数档位一致？时间线锚点一致？卷末里程碑一致？
- [ ] **卷纲 ↔ 分章规划**：总章数一致？单元划分与章节范围一致？关键事件顺序一致？
- [ ] **分章规划 ↔ 细纲**：已生成细纲的章节与分章表逐项对齐（事件/钩子/字数目标）？
- [ ] **卷纲内部自洽**：标题档位 vs 正文节（如「对标结构坐标」）内残留旧值？
- [ ] **总纲内部自洽**：时间锚点叙述、主线阶段、卷末里程碑三处互相一致？
- [ ] **总纲的「用户确认」表述**：标注「用户确认档位」的值是否仍是最新决策（用户改过口但文件没跟上）？

## 2. 跨文件事实核对（横向事实字段）

- [ ] **已砍设定残留**：向用户确认过的「砍除 XX 线 / 删除 XX 设定」→ Grep 该关键词在全部关联文件的残留（对普通项目搜 大纲/+设定/；同人项目加 原著/时间线对比）；
- [ ] **字数档位**：总纲 / 卷纲标题 / 分章规划（章数 × 每章字数下限）三处互算一致（如 62 章 × 3800 ≈ 23.5 万 ≠ 30 万即矛盾）；
- [ ] **主角事实字段**：年龄、入学/入队时间点、开局状态在各文件一致；
- [ ] **书名**：各文件标题 vs 工作区目录名（两处用户确认文件一致时以文件为准，目录名可能只是工作区名）；
- [ ] **关键事件锚点（同人重点）**：首次交集 / 关键转折发生在哪一章段，总纲 / 卷纲 / 分章规划 / 时间线对比双轨四方一致；
- [ ] **题材定位 / 文风**：定位表述、爽点来源清单、卖点关键词与最新决策对齐（旧爽点来源可能引用已砍设定）；
- [ ] **preferences.md**：用户偏好（视角/雷点/节奏）与设定文件无冲突；
- [ ] **时间线对比双轨**：每行事件与最新决策对齐（被砍线的事件行、旧锚点的章节范围行）。

## 3. 组织性检查（S3：只标记建议，不自动执行）

- [ ] 细纲文件平铺在大纲/ 根目录？（60+ 章会淹没目录；子目录化涉及文件迁移，需用户手动配合删旧文件）；
- [ ] 后续卷有无占位（卷纲模板 / 总纲中的粗略方向行是否够用）；
- [ ] 卷纲的伏笔清单 / 经济账 / 状态线有无对应 追踪/ 挂钩（空目录 = 脱钩）；
- [ ] 文件命名与 oh-story 规范一致（细纲_第NNN章.md 三位补零等）。

## 4. 严重级判定与产出格式

- **S1 结构级**：分层互算矛盾、主线阶段/单元数不齐、关键锚点错位、卷末里程碑过期；
- **S2 事实残留**：已砍设定残留、字数/年龄/书名等字段过期、关联文件旧表述；
- **S3 组织性**：目录结构、占位缺失、追踪脱钩、命名。

诊断报告问题行格式（Markdown 表格）：

```md
| 级 | 位置 | 旧值 | 基准值（出处） | 建议 |
|----|------|------|----------------|------|
| S1 | 大纲.md·主线阶段 | 5 段（无三步塔） | 6 单元（卷纲+分章规划自洽） | 重写阶段划分对齐卷纲 |
```

基准值必须注明出处（哪个自洽群 / 哪次用户确认）；两派并存无法判定新旧的，旧值与基准值都列候选 + 标「⚠ 待用户裁定」，进 Phase 3 问题清单。
