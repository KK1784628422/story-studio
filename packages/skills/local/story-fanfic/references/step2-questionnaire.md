# 第 1 步·专属设定：统计专属设定（15 问问卷）

> 四步制中本文件属第 1 步的 `own` 子阶段（s1.substep=own）；文件名保留 step2 仅为历史一致。

目标：问清用户在同人书里的全部专属设定，确认后生成同人侧最终设定（大纲/世界观/专属设定/关系/文风/题材定位）。

## 1. 15 问问卷（分 2 批 ask_questions，8+7）

**第一批（8 问）**：

1. **主角人设**：你的原创主角完整人设是什么？（姓名/性别/年龄/外貌气质/性格/行事风格；若非原创主角——如以原著配角为主角，请说明）
2. **金手指**：主角的金手指/外挂是什么（系统/血脉/宝物/记忆等）？具体效果？有什么限制、代价？是否对外公开？
3. **专属力量体系**：基于原著延伸的专属力量体系？（主角独有的修炼路线/变体体系；没有填「无」）
4. **全新力量体系**：超出原著框架的全新力量体系？（原著没有的力量类型；没有填「无」）
5. **同人类型**：穿越 / 重生 / IF 改写剧情 / AU 平行宇宙 / 续写原著 / OC 插入主线——选哪种或组合？
6. **时间节点**：故事发生在原著哪个时间节点（原著开篇前/某事件前后/原著中期…）？是否修改原著关键事件？
7. **原著角色改动许可**：原著角色严格遵守原著人设，还是允许适度改动？有没有需要改动生死状态的角色（救活谁/写死谁）？
8. **出身与阵营**：主角出身背景、初始所属势力？后续阵营会变化吗？

**第二批（7 问）**：

9. **核心追求**：主角的核心追求、动机是什么？
10. **初始关系**：主角与原著主要人物的初始关系（敌/友/中立，逐个列）？需要新增原创配角、敌人、盟友吗？
11. **新势力**：是否创建全新势力/种族/门派？有则说明立场、实力、与原著势力的关系。
12. **风格与结局**：故事整体风格倾向？结局希望 HE（圆满）/ BE（悲剧）/ 开放式？
13. **剧情禁忌**：有没有不希望出现的剧情、情节禁忌？（如：不接受主角吃瘪超过 X 章/拒绝某 CP/不写某角色黑化）
14. **冲突优先级**：原创设定和原著设定冲突时，以原著为准还是以原创为准？（逐类说明：力量体系/事件走向/人物性格）
15. **创作目的与终局**：这本同人的创作目的？最终基于原著达到怎样的结局？

**问询纪律**：
- 问题逐字使用上文表述（用户措辞可微调但信息点不缺）；
- 每题附简短说明示例，方便用户作答；
- 用户跳过的题标注「未指定，按默认」并在总结中列出（默认策略见下）。

**默认策略（用户未指定时）**：金手指低调不公开；原著角色严格守原著人设；冲突优先级=原著为准（除主角专属线）；结局开放式；无禁忌。

## 2. 设定总结确认

汇总 15 问作答 + 第 1 步原著设定要点，输出「同人设定总结」全文（结构 = 下文落盘清单的浓缩版），请用户确认：
- 用户答「否/有问题」→ 让用户补充修正 → 重新输出总结循环；
- 用户确认 → 落盘。

## 3. 落盘清单（同人侧，oh-story 标准结构）

| 文件 | 内容 |
|------|------|
| 大纲/大纲.md | **只写已知**：同人类型、时间锚点、主角线一句话、预期卷数（待拆书校准）、标注「初版骨架——第 3 步完善」 |
| 设定/世界观/背景设定.md | 原著背景引用（`基于原著：原著/世界观.md`）+ 同人新增背景（AU 差异/新地图等） |
| 设定/世界观/力量体系.md | 原著体系引用 + 专属力量体系（第 3 问）+ 全新力量体系（第 4 问）+ 战力对照表（原著标尺 vs 主角成长线） |
| 设定/同人核心设定.md | 金手指（效果/限制/代价/保密性）、专属物品（超出原著的物品技能）、同人类型与时间锚点、原著角色改动许可清单、剧情禁忌 |
| 设定/角色/{主角名}.md 等 | 原创角色卡（主角必建；新增原创配角/敌人/盟友逐个建）；引用原著角色不重复建卡，写「见 原著/角色/{名}.md」 |
| 设定/势力/{新势力名}.md | 新建势力卡（第 11 问）；原著势力引用不重复建 |
| 设定/关系.md | 「关系总览」表格（含原著角色与原创角色；格式同第 1 步）+ 初始关系说明（第 10 问） |
| 设定/文风.md | 风格倾向（第 12 问）→ 文风要求（节奏/对话密度/描写风格；对标原著文风可注明「参考 原著/ 检索印象」） |
| 设定/题材定位.md | 题材（同人+原题材）、读者画像、核心爽点、终局方向（第 15 问） |
| 设定/题材正文提示卡.md | 按 story-long-write 的题材提示卡格式 + **必含「同人纪律」块**（见下） |

**「同人纪律」块（写入 设定/题材正文提示卡.md，每章写前必读）**：

```md
## 同人纪律（每章写前对照）
1. 忠于已拆原著时间线：写前对照 原著/拆书/第{V}卷/时间线.md 与 原著/时间线对比_第{V}卷.md。
2. 时间线溢出检查：本章剧情时间逼近或超出 _progress.json 最近确认卷的 timelineThrough 时，
   停下告知用户「时间线溢出，是否继续拆解后续原著」；用户确认不拆可自由发挥并记录备注。
3. 原著角色言行符合 原著/角色/ 静态卡（终局实力上限、OOC 红线）；原著角色戏份符合其原著时段的位置。
4. 原著角色/设定改动许可以 设定/同人核心设定.md 的许可清单为准（未列出的默认守原著）。
5. 冲突优先级按 设定/同人核心设定.md 逐类执行（默认：力量体系/事件走向以原著为准，主角专属线以原创为准）。
```

**回写进度**：落盘后 Edit _progress.json（四步制 v2）：s1.status='done'、step=2。提醒：「第 1 步（设定）完成。建议新开会话，输入『继续同人』；在第 2 步面板上传原著第一卷原文后开始拆书。」
