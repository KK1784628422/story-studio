# 第 3 步：完善卷纲与细纲（核心）

> 四步制中本文件对应第 3 步（卷纲与细纲两个子阶段）；文件名保留 step4-5 仅为历史一致。

目标：基于已拆书并确认的原著卷时间线，生成本书的卷纲与全部细纲，逐章经用户确认（面板勾选确认变绿）。

**本书卷由面板登记**：用户在拆书页「新建卷纲」弹窗勾选本书卷对应的原著卷（可多选）并填卷名/预计章节数 → \_progress.json 的 s3.ficVolumes 出现条目（id=本书卷号）。卷纲阶段先读该条目获取卷名/章节数/对应原著卷，缺剧情方向/字数等再问询。

**目录与编号约定（必须严格遵守）**：每本书卷一个子目录——`大纲/第{id}卷_{卷名}/`（目录路径已登记在 ficVolumes[].dir，**直接用该值**，不要自己拼）；本卷的卷纲与细纲都放进该目录：`{dir}/卷纲.md`、`{dir}/细纲_第NNN章.md`；总纲仍在 `大纲/大纲.md` 根。时间线对比文件按本书卷号命名（`原著/时间线对比_第{id}卷.md`）。细纲按全书连续章号，章号区间按 ficVolumes 登记顺序累加预计章节数推导（卷1 = 1..N，卷2 = N+1..），与面板的逐章勾选确认一一对应。

## 第 3 步·卷纲阶段：完善本卷设定

### 1 问询（ask_questions，一次 ≤10 题可拆两批）

1. **第一卷内容**：第一卷写什么主线剧情？（一段话；可给 2-3 个方向供选——方向从「同人类型 × 原著第一卷时间线」推导）
2. **第一卷字数**：预计字数？（给档位：30 万/45 万/60 万——对应网文单卷常规体量；结合原作第一卷章数建议）
3. **时间线锚点**：本卷对应的原著卷已由面板登记（ficVolumes[].sourceVolumes，可多卷）；分岔点读 \_progress.json 各原著卷的 volumes[].forkEvent（用户已在面板第 2 步卷详情的「时间线」页签点选）——有则以之为准，同人剧情从该事件展开；无则展示已拆原著时间线概览（原著/拆书/第V卷/时间线.md），让用户选同人本卷的起止：
   - 起点：原著开篇前 / 原著开篇同期 / 原著某事件后（列出候选项）
   - 终点：写到原著哪个事件为止 / 自定里程碑
4. **补充**：本卷新增角色/势力（若无则略）；本卷主题情绪（爽感推进/憋屈反转/日常温馨…）。

### 2 产出（问询确认后依次落盘）

| 产物 | 要求 |
|------|------|
| 大纲/大纲.md（修订） | Edit 更新为真实结构：第一卷细化（时间锚点、主线、卷末里程碑）、后续卷只写粗略方向（待后续拆书校准）；总字数按第 2 步预期修正。有 原著信息.md 分段表时，后续卷方向可直接按表中段落行粗排（如「第二卷 ≈ 〈段落丙〉121–172 + 〈段落丁〉173–206」） |
| 大纲/卷纲_第1卷.md | 按 oh-story 卷纲模板：对标结构坐标（可用 原著/拆书/第1卷/节奏参考）+ 剧情单元（承接原著事件轴，标注同人分岔点；分段表的段落名可作剧情单元命名参考）+ 情绪弧线（含章节定位）+ 人物弧线（主角 + 出场原著角色）+ 伏笔 + 反转 |
| 原著/时间线对比_第1卷.md | **结构化双轨表**（前端同人面板渲染双泳道），格式严格如下 |

**时间线对比文件格式（逐行严格，前端解析依赖）**：

```md
# 第1卷 时间线对比（原著 vs 同人）

<!--fanfic-timeline v1-->
| 序 | 轨道 | 故事时间 | 事件 | 出处 |
|----|------|----------|------|------|
| 1 | 原著 | 〈原著历法时间〉 | 原著第1卷开篇事件 | 原著/拆书/第1卷/时间线.md |
| 2 | 同人 | 〈原著历法时间〉 | 主角穿越分岔点 | 大纲/卷纲_第1卷.md |
| 3 | 原著 | 〈原著历法时间·后段〉 | 原著中期事件 | 原著/拆书/第1卷/时间线.md |
| 4 | 同人 | 〈原著历法时间·后段〉 | 同人偏离事件（含「分岔点」标记则高亮） | 大纲/卷纲_第1卷.md |
```

规则：「轨道」只填 `原著` 或 `本书`；同一故事时间的原著/本书事件相邻排（先原著后本书）；本书偏离原著节点的事件文本含「分岔点」三字则面板高亮；「出处」填工作区相对路径。对比表覆盖本卷全部关键节点（≥8 行）。文件开头保留 `<!--fanfic-timeline v1-->` 标记行；文件名按本书卷号（时间线对比\_第{id}卷.md）；分岔点以 \_progress.json 原著卷的 forkEvent 为准。

**回写进度**：s3.status 保持 'in_progress'、s3.volume 记当前卷号，step 保持 3（卷纲与细纲同属第 3 步，全部细纲确认后才步进）。

## 第 3 步·细纲阶段：完善细纲（逐章确认）

### 1 生成

- 按卷纲分批生成 `大纲/细纲_第NNN章.md`（每批 5-10 章；oh-story 细纲模板：章节定位 + 事件 + 钩子 + 爽点 + 悬念）；
- 每章细纲**必须对照**：原著/拆书/第1卷/时间线.md（本章对应原著时段发生什么）、原著/角色/ 静态卡（本章出场原著角色此时的状态按「原著发展史」对应时段取值，不提前泄露后期实力）、原著/时间线对比_第1卷.md（本章处于哪段双轨）；
- 细纲文件走 light 门禁（Write 自动触发，报告问题按提示修）。

### 2 逐章确认

- 每批生成后在聊天展示要点清单，用户逐章确认或提意见：
  - 意见 → Edit 对应细纲 → 再展示；
  - 确认 → 下一批；
- 用户在面板逐章勾选细纲并「确认已完善」→ ficVolumes[].confirmedChapters 追加章号（面板接口写入，Agent 只读）；本卷全部章确认后面板可进第 4 步；
- 提醒：「本卷细纲全部确认。建议新开会话，输入『继续同人』进入第 4 步正文创作。」

### 3 后续卷的循环

循环拆书：下一卷正文完成后回第 2 步上传新卷原文并再次「新建卷纲」登记本书下一卷；每卷重复第 3 步（卷纲 + 细纲 + 新的时间线对比文件），ficVolumes 按登记顺序推进。
